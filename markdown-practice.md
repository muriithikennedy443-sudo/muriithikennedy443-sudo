<h2>Steps to make a Commit in Git</h2>

1. **Open a terminal** or a **command prompt**.
2. **Navigate to your project folder** using `cd path/to/your/project`.
3. **Check the status** of your repository with `git status`.
4. **Stage the changes** that you want to commit using `git add filename`.
5. **Commit the changes** with a message using `Your commit message`.
6. Lastly,**verify your commit** by checking the log with `git log`.
